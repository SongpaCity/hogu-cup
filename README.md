# 🏆 호구컵 (hogu-cup)

호구들의 월드컵. 둘 중 더 호구를 골라 최종 호구를 가리는 이상형 월드컵 스타일 토너먼트.

## 공유 링크

> https://songpacity.github.io/hogu-cup/

링크는 고정입니다. `index.html`을 교체·푸시하면 내용만 바뀝니다.

## 업데이트 방법

1. `index.html`(또는 콘텐츠 파일)을 교체한다.
2. 커밋 & 푸시:
   ```bash
   cd ~/hogu-cup
   git add -A
   git commit -m "update"
   git push
   ```
3. 약 1분 뒤 위 링크에 반영됩니다.
